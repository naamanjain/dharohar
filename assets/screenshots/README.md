# DHAROHAR — Screenshot Evidence Pack

This folder is reserved for **genuine screenshots captured from the deployed DHAROHAR interface**. No mockups, generated product screenshots or screenshots from another project should be presented as live product evidence.

## Capture requirements

- Capture from the live hosted website after confirming the deployed build.
- Use only synthetic demonstration records.
- Use a dedicated judge account with least privilege once provisioned.
- Do not include real names, citizen identifiers, emails, phone numbers, passwords, session tokens or internal infrastructure details.
- Do not alter a screenshot to imply a feature or state that was not present.
- Crop browser chrome only when it adds no useful context; do not edit the application state.
- Record the capture date and verified build in the accompanying evidence index.
